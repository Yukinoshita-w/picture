    Connection

    API 设置

    分别配置图片生成和提示词优化服务。密钥只在当前标签页中使用，刷新页面会保留，关闭标签页后再打开需要重新填写。

    预设保存 URL、模型、能力和默认参数，不保存 API Key。切换预设会清空当前 API Key。

    ↗

    支持 Base URL（含 /v1）或完整图片接口地址。有参考图时会调用同一服务的图片编辑接口。

    ⌘
    ✣
    快速填入

    自动识别是常见模型的参数预设，不会探测服务商。第三方接口有差异时请选择自定义；未勾选的参数仅保留接口默认值，不会发送对应字段。

    允许的接口参数
    尺寸 size（不勾选则不发送）

    开启后可选择更多比例、2K / 4K 或输入宽高。应用接受 64–8192 像素、8 的倍数，实际范围仍以接口为准。

    画质 quality（不勾选则不发送）
    返回格式 response_format（不勾选则不发送）

    允许值仍需服务实际支持。参考图调用 /images/edits；修改能力不会自动获得该接口。应用最多生成 4 张、参考图最多 4 张。

    ⌄

    按模型能力显示可用选项；默认不发送 response_format。

    iAPI Key 仅通过本机后端转发，不会保存在浏览器或服务器。

    独立配置文本模型，仅点击“优化提示词”时调用。可以与生图接口使用不同服务。

    预设只保存 URL 和模型，不保存优化 API Key。切换预设会清空当前优化密钥。

    ↗

    支持 Base URL（含 /v1）或完整 /chat/completions 地址。

    ⌘
    ✣

    使用 OpenAI 兼容的 Chat Completions 接口。按题材优化，结合所选尺寸和张数，保留参考图编号关系，不上传参考图片内容。

    i优化为可选操作。不配置或不点击优化，也可以直接生成图片。

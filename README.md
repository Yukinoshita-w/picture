# Prompt Studio · AI 生图工作台

完整的本地 Web 应用：浏览器负责配置和展示，Node.js 后端负责请求 OpenAI 兼容的生图 API。自由白板使用 AntV X6；仓库已包含构建好的本地前端资源，直接启动不需要访问 CDN。

## 启动

安装 Node.js 20 或更新版本（建议 Node.js 24 LTS）。在本目录打开终端：

```powershell
npm start
```

打开 http://localhost:3000 。也可以双击 `启动网页.cmd`，保持启动窗口运行，再打开上述地址。不能直接双击 HTML 使用。

如果本机仍为旧版 Node，可运行 `npm exec --yes --package=node@24 -- node server.js`；首次需要联网下载运行时，后续使用 npm 缓存。启动脚本在检测到旧版本时也会使用这一方式。

端口被占用时：

```powershell
$env:PORT = '3001'
npm start
```

## 配置与使用

1. 点击右上角的设置图标打开配置弹窗，填写 API URL，例如 `https://api.openai.com/v1`，或完整端点 `https://api.openai.com/v1/images/generations`。第三方服务填写它提供的 Base URL（包括 `/v1` 等前缀）。程序会自动补全 `/images/generations`。
2. 填写 API Key 和该服务实际支持的模型名称，点击“完成设置”回到工作台。OpenAI 协议的字段是 `model`，即需求中提到的 `module`。也可按 Esc 或点击弹窗外关闭设置。
3. 可点击“测试连接”：调用同一 Base URL 下的 `GET /models` 验证鉴权，不生成图片。测试成功只说明模型列表接口可用；生图权限和额度需实际生成验证。有些供应商没有模型列表，测试会失败但仍可尝试生成。
4. 在底部输入提示词，选择尺寸、画质和数量，点击“生成图片”。结果和历史显示在上方，可独立滚动；底部输入区保持可见。也支持 Ctrl / Command + Enter。生成请求最多等待 5 分钟。
5. 点击图片查看大图，点击“下载”保存图片。最近 8 张图片和提示词保存在当前浏览器的 IndexedDB 中，可复用提示词或逐张删除记录。URL 图片可能过期，建议及时下载。

### 作品画廊

生成结果与最近生成记录中，“复用提示词”右侧提供“提交画廊”。提交后显示“已入藏”，同一张记录不会重复收藏。顶部“作品画廊”可查看收藏：

- **作品走廊**：按创作日期分组，支持从新到旧或从旧到新排列，以画框、留白和时间轴展示作品；可预览、下载、复用提示词或确认后移出画廊。
- **沉浸放映**：在走廊勾选“加入放映”，点击“放映所选”。中央主画、两侧透视预览与底部缩略图共同展示，支持前后切换、播放 / 暂停、5 / 8 / 12 秒间隔和全屏。聚焦画面区域后可用方向键切换、空格播放或暂停；离开画廊或切换浏览器标签页会暂停。

画廊和放映选择独立保存在当前浏览器的 IndexedDB 中，刷新或关闭页面后仍可读取，不受最近 8 张历史上限及历史删除影响。URL 图片会在提交时下载并保存副本；下载或存储失败会提示，不会显示入藏成功。这是当前浏览器的个人画廊，不会公开上传或跨设备同步；清除网站数据会一并清除收藏，重要作品请下载备份。

### 自由白板

打开“画廊 → 自由白板”，把图片自由摆放、连线，制作关系图、故事板或灵感展示。白板不调用生图或文本 API。

- **图片节点**：点击左侧画廊作品或将其拖进画布；也可以先“＋ 空节点”，选中后点击作品填入。双击空白位置可创建节点，双击图片可看大图。支持上传 PNG / JPEG / WebP，单张最多 20 MB，一次最多 20 张。
- **自由摆放**：“选择”模式可移动图片，点击后拖动四角可等比调整卡片尺寸；图片保持完整比例显示。Shift 框选或 Ctrl / Command + A 多选，支持整体移动、复制与删除。替换图片保留节点和连线。
- **图片外观**：默认仅显示图片，不带白色边框或提示词。选中图片后可勾选“显示图片边框”，并填写“自定义标题”；标题留空不显示文字。外观按图片独立保存，替换图片时保留，撤销、刷新和导出备份均支持。旧白板的提示词不会再自动显示为标题。
- **自由连线**：切换“连线”，从一张图片拖到另一张；支持多对多、回环和双向关系，不强制层级。连线统一为直线，始终位于所有图片下方；已有白板及导入的曲线、折线也会转为直线。选择连线后可修改说明、颜色、粗细、箭头与虚线，拖动两端可重新连接。
- **连线文字**：双击连线即可聚焦右侧“连线文字”输入框，输入时即时显示；修改、删空或点击“清空连线文字”均不会删除连线。文字支持撤销、自动保存与导出。
- **精细连接点**：“打点”后点击图片任意位置创建固定连接点，再切到“连线”从空心圆环拉线。圆环使用透明中心与对比描边，仅在打点和连线模式显示于图片上方；选择、平移、展示及 PNG / SVG 导出时隐藏，不遮挡作品展示。连接点按比例保存，跟随节点缩放；清除连接点时，关联连线会保留为普通节点连接。
- **画布操作**：滚轮缩放，切换“平移”或按住鼠标中键拖动画布；“适应画面”查看全部内容。V / C / H / P 分别切换选择 / 连线 / 平移 / 打点。快捷键在画布获得焦点时生效，不拦截输入框。
- **撤销与重做**：工具栏按钮或 Ctrl / Command + Z、Ctrl / Command + Shift + Z；保留当前白板最近 100 个历史操作，重新打开或切换白板后清空操作历史。
- **多白板与保存**：可新建、重命名、切换和确认后删除白板。布局、连线、连接点和视口自动保存在独立的 IndexedDB `prompt-studio-whiteboards`。底部显示保存状态，保存失败时可以重试或导出备份；多个标签页修改同一白板时会阻止覆盖并提示备份、刷新。
- **展示与导出**：“展示”隐藏编辑面板并禁止修改，可平移、缩放和全屏。支持 PNG / SVG 导出，以及包含原图的 JSON 白板备份；导入始终创建新白板，不覆盖现有白板。备份文件最大 160 MB；超大范围请使用 SVG，PNG 受浏览器像素上限限制。

图片加入白板时会保存独立资源副本，并在白板内去重。以后将作品移出画廊或替换系列作品，不会破坏白板；原图用于预览、导出与备份，编辑时使用缩略图。替换或删除节点后的旧资源暂时保留，以支持撤销。白板不跨浏览器或设备同步，清除网站数据会删除白板，请定期导出备份。

### 参考图生成

在底部点击“参考图”选择图片，也可把图片拖入提示词区域，或在输入框里粘贴剪贴板图片。支持 PNG / JPEG / WebP，最多 4 张，单张最多 10 MB，总计最多 20 MB。缩略图按顺序显示，可点击预览、点击 × 移除。

添加参考图后自动切换为图生图。每张参考图都可以选择人物、构图、风格、产品外观或自定义用途，并填写需要保留、需要修改的内容；这些说明会按“参考图 1”等编号加入生图提示词。提示词中仍可以写“保持参考图 1 的人物，将背景替换为参考图 2 的场景”等描述。没有参考图时仍然是文生图。生成后保留参考图，方便继续调整提示词；刷新页面会清除参考图。

参考图功能使用 `POST /images/edits`，按 multipart/form-data 上传真实图片文件和提示词；单张使用 `image`，多张使用 `image[]`。Base URL 或完整 `/images/generations` / `/images/edits` 地址会自动转换到同服务的正确接口，保留 URL 查询参数。

需要 GPT Image 或兼容该图片编辑接口的模型。自动识别模式中 DALL·E 2 / 3 的参考图功能关闭；第三方兼容服务若实际支持相应编辑接口，可按文档自定义能力。第三方服务还需实际开放编辑接口和多图能力；仅支持文生图的供应商不能因此获得参考图能力。参考图不会写入服务器磁盘或浏览器持久存储，生成时发送给配置的 API 服务。

### 系列创作

顶部导航的“系列”把一组画面当作一个项目来管理，核心是让同一系列里的每张图共享同一份视觉定义。

**三个概念。** 「系列」是容器；「风格圣经」是系列内不变、逐字进入每条提示词的视觉定义（媒介、色板、光线、镜头、构图、调色、角色外观、术语、负向约束）；「图库」是系列级的参考图集合。帧是单张画面，每帧只描述这一张独有的内容。

**刚建好系列时。** 空白系列的大纲页会显示三步引导：① 定义圣经（手填，或从主题提炼）；② 上传参考图；③ 添加帧并生成。每一步都有直达按钮。只有「帧」和「图库」都为空时才会出现，建好第一帧后自动隐藏。

**模型配置。** 系列走和「优化提示词」完全相同的路径与配置：提炼、看图、拆分帧、单帧扩写都使用**提示词优化 API** 里的 URL、Key 和文本模型；只有最终生成图片使用**图片生成 API**。两套配置分开填写，避免用生图模型去调 Chat Completions 时报“请求参数错误”。若提示词优化 API 未配置，会回退到图片生成 API 的同一套值。看图要求所填文本模型能读取图片输入。

**创建流程。** 新建系列后可以粘贴任意长度的主题原文（几万字也可），点击「从主题提炼」后：长文先按标题和段落切块，逐块交给文本模型读出角色、场景、道具、视觉线索和禁忌，再汇总成结构化的风格圣经草稿。提炼默认并发 2 块，显示进度，可随时暂停；已完成的块即时保存，再次提炼会跳过它们、不重复计费。相同原文 + 相同模型 + 相同提示版本会直接命中缓存，不产生调用。

**查看大图。** 系列里所有图片都可点击放大：帧缩略图、详情面板里的生成结果、参考图槽位、图库卡片。生成结果的说明栏也提供「查看大图」按钮，和创作页共用同一个预览框。

**从档案拆分帧。** 「从档案拆分帧」会打开一个对话框：勾选要读取的档案条目（默认全选）、填写拆成几帧（1–24，也可点 3 / 6 / 9 / 12 预设），然后由文本模型按原文顺序切成若干帧的文字描述（标题、主体、动作、场景、细节），**不生成任何图片**。每帧会记住自己取材的档案条目并挂到「引用设定」。拆分完成后会直接询问是否立即批量生成这些帧，同意则按当前圣经与图库逐张出图；也可以先逐帧修改再生成。

**选择帧批量生成。** 大纲顶部提供「全选」与「批量生成所选（N）」。勾选任意帧后点击按钮，只会生成你选中的那些帧，不会动其他帧；已经出过图的帧被选中时会重新生成，旧图会被替换删除。矩阵页的「生成待生成的帧」仍然是一次补齐所有未出图的帧，两者互不影响。

**矩阵是什么。** 矩阵是「同一套风格，换变量」的批量视图。在「圣经」底部定义可变轴（例如场景：邮局/天桥，时间：雨夜/凌晨），矩阵会把这些取值做笛卡尔积，每种搭配一行。可以逐行「建帧」，也可以一次「按轴展开全部帧」，然后「生成待生成的帧」批量出图。它和大纲的区别是：大纲按叙事顺序看帧，矩阵按取值组合看覆盖情况，用来确认「每个场景 × 每个时间都出了吗」。

新建时也可以从 5 个内置骨架开始：角色设定集、产品上市、绘本故事、品牌海报、旅行日记。模板只预填风格字段、可变轴和几帧结构，不调用模型；主题、角色和具体内容仍需要你替换。

**图为第一杠杆。** 在「图库」上传角色、风格、场景或道具图。上传时会自动重编码：长边不超过 2048 像素、单张压到 1.5 MB 以内、单帧最多带 4 张且合计不超过 6 MB，因为接口限制是 4 张 / 20 MB，而 base64 还会膨胀三分之一。配置了支持图片输入的文本模型后，可以点「分析」让模型描述这张图，再把描述写进圣经——这样即使某帧没带图，文字锚点里仍有角色特征。

**一致性靠四件事。** ① 圣经提供共同风格与角色特征，本帧指定的场景、时间、景别和机位覆盖对应默认值，角色外观、产品外形与标识保持稳定；② 每帧按固定优先级装配参考图：角色、风格、场景/道具、上一帧，编号与上传顺序一致；③ 生成启动时固定模型、尺寸、画质和返回格式，结果保留实际条件；④ 出图后计算色板、亮度和感知哈希，与系列首张图比对，差别过大时标记「偏离」并提示加强锚点重生成。

**变量与矩阵。** 帧选择的变量名称和值会写入「本帧变量」提示词，支持场景、时间、景别、机位及自定义轴。提示词预览包含参考图说明与生成要求，和实际发送内容一致；可识别的相反要求会列出冲突来源，并阻止生成，修改后可继续。未选择变量的旧帧沿用原有描述，已移除轴的历史取值仍可查看和清除。

矩阵计算全部有效轴的组合总量，每次最多显示并建立前 200 组完整组合。例如 24 × 24 × 2 会显示总计 1,152 组，前 200 组均包含三个轴。建帧只创建草稿，不调用模型；重复点击、逐行建帧或调整轴顺序会跳过已有组合。需要其他组合时可减少轴取值后再建帧；图片生成仍需另行发起。

**生成与批次。** 每帧固定生成 1 张，不做候选。单帧可单独生成；「矩阵」按可变轴展开组合后批量生成，串行执行、可暂停、可取消、失败项手动重试（不会自动重试以免重复计费）。批次条会按你填写的单价显示预估费用，开始前二次确认。中途关闭页面会丢失进行中的请求，但已完成的帧会保留。

单帧生成启动后，切换系列或页面不会改变结果归属。结果记录启动时的提示词、模型、尺寸、画质、返回格式、参考图绑定和风格版本；生成中修改条件只影响后续请求。当前帧和所属系列在生成完成前暂不可删除，重复点击不会再次提交。

快速切换系列只应用最后一次打开的结果。上传图片、从画廊组成系列，以及提炼、拆帧、扩写和参考图分析，均按操作启动时的系列保存；删除目标后不会由迟到响应重新创建。关闭拆帧对话框会取消未完成结果，关闭提炼会暂停并保留已完成分块；已发出的模型请求可能计费。关闭单帧详情后，扩写会继续保存到原帧。

**从已有作品开始。** 作品画廊里勾选若干件作品后点「组成系列」，或在创作页的结果上点「设为系列锚点」，都会把这些图变成新系列的帧，第一张自动设为默认风格锚点。图片会经过与上传相同的压缩流程。

**系列图片入画廊。** 系列里每张出图都可以单独「加入画廊」；大纲右上角的「全部加入画廊」会一次收走所有已生成、尚未入藏的帧，已经入藏的不会重复提交。入藏的是独立副本，之后删除系列不会影响画廊里的作品。画廊把同一系列的图收成一本「系列集」：收起时是一张 16:9 封面（SET 编号、系列名、帧数、更新时间印在图上），点「展开联系表」才在书架下方铺开带编号的单帧；其他系列的封面留在原位，不会被挤走。没有系列归属的单张作品仍按日期留在下方走廊。这样 20 帧的系列只占一格，不会淹没整面墙。放映时系列集可以整组加入，也可以在展开后逐帧勾选。

**长文与档案。** 「档案」存放小说片段、设定集这类原文。点「＋ 添加原文」在弹窗里填标题和正文即可保存；原文完整留在本机。条目不会自动进入提示词——在某一帧的详情面板里勾选「引用设定」，被勾选的条目才会加进那一帧的提示词，每帧最多 3 条。导出系列包（JSON，含图片与提炼缓存）后可换机导入。

系列数据保存在浏览器独立的 IndexedDB `prompt-studio-series` 中，不影响「最近生成」与「作品画廊」。提炼与看图会把原文和图片发送给「图片生成 API」所配置的服务商；生成图片时也发送给同一个服务。

删除系列、删除帧、移出图库、删除档案和开始批量生成都会先弹应用内的确认框（按 Esc 或点取消都不执行），不使用浏览器原生弹窗。

### 提示词优化（手动可选）

在右上角设置中切换到“提示词优化 API”，单独填写 URL、API Key 和文本模型。它与图片生成 API 独立，可以使用另一家供应商；支持包含 `/v1` 的 Base URL 或完整 `/chat/completions` 地址，使用 OpenAI 兼容的 Chat Completions 协议。这里可单独测试连接、完成设置和清除密钥，无需先填写图片生成配置。

输入描述后，点击“生成图片”左侧的“优化提示词”。后端调用 `POST /api/optimize` 转发到文本服务，以非流式 `messages` 请求优化构图、光线和细节，同时保留原语言、主体和限制。优化完成后会先打开原提示词与优化结果的对比弹窗；可以编辑优化结果，点击“采用优化结果”才会写入输入框，也可以关闭、按 Esc 或点击“保留原提示词”。采用后仍可点击“撤销优化”恢复；优化失败保留原提示词。

优化按钮左侧可选择“轻度润色 / 标准优化 / 丰富细节”，默认标准优化，选择保存在当前浏览器。轻度仅整理已有描述；标准按题材适度补充必要的视觉信息；丰富可围绕原主题扩展场景和视觉细节。每次优化结果弹窗会标明本次强度；任何档位都应保留明确主体、数量、文字与限制，不虚构品牌卖点、身份或参考图内容。该选择只影响手动优化，不改变生图参数或自动触发请求。

只有点击“优化提示词”才发送改写请求。完成配置、输入文字、上传参考图、点击生成或 Ctrl / Command + Enter 均不会自动优化。优化完成后也不会自动生成图片。测试连接仅请求模型列表。

顶部导航中的“风格模板”提供电影感、杂志编辑、插画、3D、建筑、自然、产品、平面设计和人物等视觉方向的模板。模板支持分类筛选和关键词搜索，可查看参考图与完整提示词，也可以一键载入提示词继续修改。

有参考图时，优化接口收到提示词、参考图数量、每张图的用途说明及当前画布上下文，要求保留编号关系，不上传图片内容。两个 API Key 保存在当前标签页的 sessionStorage 中，因此刷新页面会保留，关闭标签页后再打开需要重新填写；URL 和模型名称独立存入 localStorage。

优化规则写在 `prompt-optimizer.js`：依据动物、自然风景、建筑、产品、食物、时尚、车辆、科幻奇幻、抽象、平面设计、插画、3D、UI 信息图、头像壁纸封面等 14 类题材补充视觉描述，按“主体 → 特征 → 状态 → 环境 → 构图 → 光影 → 风格 → 画质 → 比例 → 负面约束”组织。混合题材结合相关清单，不会将所有类型套用人物模板。

优化还会收到当前选定的画布尺寸和生成张数，防止与页面比例冲突，生成张数与主体数量区分处理。输入中的 `--ar`、`--no` 和平台权重语法应改写为自然语言；输出不新增 Midjourney / Stable Diffusion 的私有参数。负面约束按题材选择，并保留需要的文字、Logo、产品标识和指定风格。未提供的身份、精确品种、品牌卖点和参考图内容不应被虚构。规则是对文本模型的指令，实际改写质量仍取决于所配置的模型，可手动编辑或撤销。

尺寸、画质默认由接口决定，避免发送服务不支持的参数。GPT Image 提供 low / medium / high；DALL·E 3 提供 standard / hd，单次只能生成一张。模型名称可自由填写，实际支持的参数以供应商为准。未知模型的可选参数可能不受其支持，优先使用默认值。

点击生成时，所选尺寸（像素宽高、比例、横竖方向）、画质及多张生成要求会自动追加到发送给生图服务的提示词末尾，文生图和参考图生成均适用；原有接口参数仍会发送。输入框下方可展开“将随提示词发送的生成要求”查看实际附加内容。选择“由接口决定”不追加对应限制；优化强度仅用于手动优化，不作为画面要求。追加内容不会写回输入框，连续生成或更改选项不会积累旧要求。提示词表达的是生成要求，最终输出像素仍由模型和服务决定。

点击“尺寸”打开尺寸设置弹窗，可选择自动、按比例或自定义宽高，并随时切回“由接口决定”。按比例提供 1K / 2K / 4K、八种常用比例及自定义比例；按长边计算并对齐至 8 像素，优先匹配接口标准尺寸。点击“应用尺寸”才保存，取消或关闭不改变当前尺寸。当前配置不支持的选项会禁用。

若服务商支持自由宽高，在 API 设置 → 自定义能力中开启“支持自定义尺寸”，即可使用更多比例和高分辨率。应用接受每边 64–8192 像素且为 8 的倍数，实际可用范围仍以服务商文档为准。自定义尺寸会随默认参数及配置预设保存，并用于提示词优化的画布上下文。

### 模型能力配置

图片生成 API 设置中可选择“自动识别”或“自定义能力”。自动识别根据常见模型名称提供尺寸、画质、返回格式、张数和参考图的预设；第三方服务即使兼容 OpenAI 格式，也可能只支持其中一部分字段。选择“自定义能力”后，按服务商文档勾选允许发送的 `size`、`quality`、`response_format`，设置最大生成张数、参考图数量和 multipart 上传字段 `image` 或 `image[]`。未勾选的参数不会发送，选择“由接口决定”也不会发送该字段。

能力配置会保存在当前浏览器，但不包含 API Key。后端会再次校验配置和请求值；能力上限不足时在调用供应商前返回错误。配置只描述服务实际支持的能力，不能让仅支持文生图的服务获得 `/images/edits` 参考图能力。

### API 配置预设

图片生成和提示词优化设置页各有独立的“配置预设”。填写有效的 URL、模型和预设名称后点击“保存”，无需先填密钥。图片预设同时记录模型能力及工作台当前选择的尺寸、画质、数量和返回格式；优化预设只记录 URL、文本模型。保存使用相同名称会更新已有预设，输入新名称会新增一套。

选择预设会加载对应配置，自动刷新可用选项并清空该服务的 API Key，需要重新填写；另一套 API 配置和密钥不受影响。选择“不使用预设”保留当前配置并清空对应密钥。删除只移除预设，保留当前正在使用的配置。保存、切换和删除都不会调用 API 或生成图片。

预设、当前预设标记及默认参数保存在当前浏览器，刷新后仍可使用，但不会保存或恢复 API Key。存储不可用时会提示保存或删除失败；更新当前配置不会自动覆盖已保存的预设，需要点击“保存”更新。

### 等待、取消与超时

生成图片或优化提示词时，工作台会显示已等待秒数和“取消”按钮。取消会立即恢复提示词、参考图和设置操作；生成中的上一次成功结果会保留，只有新请求成功才替换结果。取消或超时后都不会自动重试，也不会打开优化结果弹窗。

本地后端默认最多等待 5 分钟；超时会显示独立的超时状态。浏览器断开或点击取消时，后端会尝试中止对应的供应商请求。供应商可能已经接收任务，因此取消不能保证停止其后台处理，也不能保证不产生费用。

### 错误诊断

供应商返回错误时，状态栏会显示分类、处理建议和脱敏后的原始信息。当前会区分鉴权失败、权限不足、模型或接口不存在、额度受限、请求过于频繁、请求参数错误、参考图接口错误、网络连接失败、服务商错误和超时。429 只有在响应内容明确表示额度或计费问题时才归类为额度受限，否则显示为请求过于频繁。

“测试连接”只请求 `/models`，成功只代表鉴权和模型列表可用，不代表模型一定有生图权限、额度或参考图能力；仍需通过实际生成验证。生图失败后不会自动重试，避免重复提交可能已经计费的请求。

图片返回格式默认不传 `response_format`，兼容 GPT Image；能力配置允许时可手动指定 `b64_json` 或 `url`。后端同时支持两种返回。

## 调用流程

```text
浏览器 → POST /api/generate → 供应商 /images/generations → 图片 → 浏览器
```

后端发送 `Authorization: Bearer <API Key>` 和 JSON：

```json
{
  "model": "你填写的模型名称",
  "prompt": "你的提示词",
  "n": 1
}
```

选择参数后额外发送 `size`、`quality`、`response_format`。返回须符合 OpenAI Images 格式，例如：

```json
{"data": [{"b64_json": "..."}]}
```

或 `{"data":[{"url":"https://..."}]}`。支持同步 Images 生成和编辑接口；不包含供应商私有异步任务协议、Responses API 或局部蒙版编辑。

## 数据与运行范围

- API Key 仅保留在当前标签页的 sessionStorage 中，并随请求发送给本机后端和配置的供应商，不写入磁盘或服务日志。刷新页面会保留，关闭标签页后再打开需要重新填写。
- API URL、模型、能力配置、预设、默认参数和主题存入 localStorage；图片和提示词存入 IndexedDB。存储不可用时图片历史仅保留在当前会话。
- 系列数据存放在独立的 IndexedDB `prompt-studio-series` 中（系列、帧、图库、批次、档案、提炼缓存），与“最近生成”和作品画廊互不影响。删除系列会连同其帧与图片一起删除。
- “最近生成”最多保留 8 张图片；每张图片右下角提供“删除”按钮，位于“下载”左侧，点击后需再次确认才会删除对应历史记录，取消则保留。删除仅影响本机浏览器中的历史记录，不影响已下载的文件。
- 服务绑定 `127.0.0.1`，仅供本机使用，拒绝跨站 API 请求。请仅填写你信任的 API 地址。
- 如果将来需要部署给多人使用，需要另行加入 HTTPS、账号鉴权、供应商地址白名单、请求限流和服务端密钥管理。当前版本为本地使用版。
- 后端网络必须能够访问 API。浏览器能打开供应商网站不代表 Node 请求必然可用；本机代理须能够覆盖 Node 流量。
- 页面使用系统字体，无需加载外部字体资源。

## 白板开发与检查

修改 `src/whiteboard.js`、`src/whiteboard-model.mjs` 或 `src/whiteboard-store.mjs` 后，在 Node.js 20+ 下执行：

```powershell
npm ci
npm run build
npm run test:whiteboard
```

`npm run build` 使用 esbuild 将 X6 和白板代码打包到 `public/whiteboard.bundle.js`，并生成本地 vendor CSS 与第三方许可文件。发布时需保留这些生成文件；已构建应用运行时不依赖 `node_modules`。白板进入时才加载编辑器，继续使用现有同源 CSP，不开放远程脚本或内联样式表。

`npm run test:whiteboard` 包含白板数据校验与真实浏览器回归；浏览器检查需要 Python 3、Chrome 或 Edge，使用独立临时配置和本地服务，不使用真实密钥，不产生模型费用。截图、临时配置与导出结果写入 `test-results/`。`npm test` 还会运行现有本地 `tests/` 中的生成、优化和系列检查。

系列浏览器检查使用相同的 Python 和浏览器环境，以及仓库内的本地模拟 API：`npm run test:series` 验证系列工作台全流程，`npm run test:series-generation` 用可暂停返回的响应验证单帧生成归属、失败隔离、启动条件快照、重复提交和删除保护。测试复用 `checks/browser_driver.py`，数据写入独立测试配置，不影响日常浏览器数据；模拟图片不能验证真实模型的画面质量。

`npm run test:series-async` 验证读取、上传／压缩、去重、删除和画廊组成系列的异步归属；`npm run test:series-models` 验证提炼、拆帧、扩写和看图的延迟返回、失败、目标删除及对话框关闭。所需源码和模拟服务均随仓库交付。

`npm run test:series-storage` 验证生成图片、帧结果和旧图替换的事务提交；注入事务中止、空间不足和持续写入失败，检查旧图保留、无孤立资源或虚假结果、跨系列隔离，以及刷新和断网后读取本地图片。

`npm run test:series-matrix` 验证变量覆盖与冲突拦截、预览／上游请求／结果提示词一致（含参考图）、1,152 组总量与前 200 组完整性，以及建帧去重、轴重排、ID 唯一性、事务回滚、跨系列隔离和手机布局。建帧测试确认没有调用生图模型。

远程链接出图会先下载为本地资源，再采用新图。下载或保存失败时保留原图与“待保存”记录，可在帧详情点击“重试保存图片”，不会重新调用生图模型；刷新后仍可手动重试，链接过期则无法保证恢复。旧远程图片可通过“保存到本地”处理。`npm run test:series-remote` 验证下载失败、损坏图片、保存重试、刷新恢复、系列包、空间不足、跨系列隔离、批次待保存提示及手机布局。若连待保存信息也无法写入浏览器，会保留临时记录并提示勿刷新。
